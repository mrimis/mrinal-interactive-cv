Current work

Three things I am building now at the Perera Lab.

Perera Lab BioPortal

Full-stack web app for running genomics tools from a browser

A web platform for authenticated lab users to upload genomics files, queue command-line bioinformatics jobs, monitor progress, and download analysis outputs from a browser-based workflow.

  1. InputLarge genomics files, metadata, parameters
  2. EngineValidated uploads, queued jobs, tool registry
  3. OutputReports, plots, logs, downloadable bundles
  • Built around Django 5.2, Django REST Framework, React, Bootstrap, Celery, Redis, Docker, and production-style deployment patterns.
  • Supports chunked uploads, file validation, background job execution, session and auth flows, audit logging, and output download bundles.
  • Tool catalog includes PLINK 1.9/2.0, GCTA, Beagle, FLARE, GWAS/TWAS, variant-calling, RNA-seq, and QC-oriented workflows.

Review the sanitized source snapshot on GitHub

The public repository is a portfolio-review snapshot only. It is not a production deployment, not an official Northwestern University release or endorsement, and it grants no open-source reuse license. Research data, uploads, secrets, outputs, and third-party binaries are removed.

ALA_GEM

Local-ancestry-aware gene expression modeling

A focused modeling project for local-ancestry-aware gene expression prediction, designed to evaluate how ancestry-informed features can improve transcriptomic prediction and downstream disease-relevant analyses.

  1. InputGenotype, local ancestry, expression, covariates
  2. ModelNested cross-validation and ancestry-aware predictors
  3. ReadoutPrediction performance and gene-level summaries
  • Developed training and validation workflows around genotype, local ancestry, expression, and covariate data on hg38.
  • Worked with chromosome-level runs, nested cross-validation, elastic-net style modeling, and external validation comparisons.
  • Framed for precision-medicine use cases where population structure and local ancestry can affect prediction quality.

Ancestry-aware bioinformatics AI system

Confidential project, described here at a high level only

An AI system in development for reasoning over ancestry-aware bioinformatics questions. This page describes the product direction and scientific motivation without exposing architecture, implementation details, or patent-sensitive components.

  • Positions AI as a guided analysis layer for variant, region, population, association, enrichment, and quality-control questions.
  • Emphasizes responsible genomics use: scope control, reproducibility, warning and routing logic, and explainable summaries.
  • I am glad to discuss it further in an interview, a collaboration setting, or an NDA-protected review.
